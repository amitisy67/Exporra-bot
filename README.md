# 🌍Exporra Rubika Business Bot

## 📌 About the Project

**Rubika Business Bot** is a Python-based business assistant bot built with **rubka** for a B2B import/export business.

The project was created to provide customers with a simple and accessible way to learn about the business, explore its services, and find contact information directly through the Rubika application.

This repository contains an **anonymized version** of the original project. Private business information, names, phone numbers, and other sensitive details have been removed.

## 🤖 What Does It Do?

The bot acts as a digital business assistant. It automatically responds to user commands and provides relevant information about the business.

Users can interact with the bot directly through the Rubika application and access information without needing to contact the business manually for basic questions.

## ✨ Features

* 👋 Welcome and introduction message
* 🌍 Business and service introduction
* 📦 Product and service information
* 📞 Contact information
* 🤝 Customer communication
* ⚡ Automatic response to commands
* 🕐 Configurable working hours

## 🛠️ Technologies Used

* 🐍 **Python**
* 🤖 **PyRubi**
* 🔌 **WebSocket**
* 🔎 **Regular Expressions**
